## Pizzaria Nonna Pizza

 Nosso projeto sera a criacacao de um sistema com objetivo de facilitar o pedido de pizzas
 e ter controle dos pedidos feitos, neste site os clientes podem 
 se cadastrar, consultar cardapio e realizar pedidos 

# Cliente
- Criação de contas
- Login  
- Criar pedidos de pizzas
- Consultar cardápio
- Cadastrar informações pessoais (endereço, forma de pagamento)

# Admin

- Cadastrar e alterar sabores de pizza
- Visualizar os pedidos que foram feitos
